### Added

- Initial SDK for the Kaseya VSA X (VSA 10) REST API v3: devices, assets, automation, notifications,
  organizations/sites/groups, custom fields, scopes, patch management, endpoint protection,
  environment, audit logs, rate limits.

### Security

- Host allow-list and redirect refusal: credentials are only sent to the configured tenant host and are never replayed to a redirect target.
- Auth circuit breaker on 401 (optional shared store), with a single-probe half-open state after the cooldown so concurrent callers cannot send bad credentials in parallel.
- Bounded retries: only 429 (all methods, capped Retry-After) and 502/503/504 (idempotent methods only); never 401/403 or other 4xx/5xx.
- Secret scrubbing of error messages, bodies and enumerable state.
