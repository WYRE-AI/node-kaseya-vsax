# node-kaseya-vsax

Node.js/TypeScript client library for the Kaseya VSA X (VSA 10) REST API v3.

Work in progress. Tracked in WYREAI-493.

VSA X (VSA 10) uses REST API v3 at `https://<tenant>.vsax.net/api/v3` with Basic Token ID:Token Secret auth. This is a different API from classic VSA 9 (see `node-kaseya-vsa`).
